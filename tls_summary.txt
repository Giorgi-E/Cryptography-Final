Wireshark TLS Handshake Analysis:

For this I checked a couple of websites such as google, facebook or youtube and the TLS version they utilize is TLSv1.3
Unfortunately for us TLS 1.3 removes and encrypts many handshake details that were visible in TLS 1.2 (like Server Certificate, Server Key Exchange, and Client Key Exchange).
So I googled for a specific website example that still uses TLS 1.2 and analyzed this website - https://tls-v1-2.badssl.com/

For this example we can see the Client Hello that initiated the handshake. Then we see the Server Hello and Certificate packets, and finally both the Server and Client Key Exchanges. 
The details can bee seen in the included wireshark screenshot.



How TLS Ensures Confidentiality and Integrity:

TLS provides confidentiality by encrypting data using symmetric encryption algorithms such as AES. After the handshake, both parties get shared symetric encryption keys, which are used to encrypt all data.
Integrity is ensured through message authentication codes that are generated using a shared secret and a hash function. 
The person on the other end recalculates this mac seperately using the same parameters and if it matches than the message has not been altered.
