I used OpenSSL for S/MIME over GPG as it is more familiar.
First we start by generating private key for Alice and creating a signed certificate using these commands:

openssl genpkey -algorithm RSA -out alice_private.key -pkeyopt rsa_keygen_bits:2048
openssl req -new -x509 -key alice_private.key -out alice_cert.pem -days 365 -subj "/CN=Alice/emailAddress=alice@hotmail.com"

Now we do the same for Bob to establish the identities of these two people:

openssl genpkey -algorithm RSA -out bob_private.key -pkeyopt rsa_keygen_bits:2048
openssl req -new -x509 -key bob_private.key -out bob_cert.pem -days 365 -subj "/CN=Bob/emailAddress=bob@hotmail.com"

Now we create a message that Alice sends to Bob:

echo "(confidential)-Hello Bobby-(confidential)" > original_message.txt

Now Alice needs to sign this message with her digital signature:

openssl smime -sign -in original_message.txt -signer alice_cert.pem -inkey alice_private.key -out signed_message.pem -text
openssl smime -sign -in original_message.txt -signer alice_cert.pem -inkey alice_private.key -out signed_message.pem -outform PEM -nodetach


And encrypt it for Bob:

openssl smime -encrypt -in signed_message.pem -out signed_message.asc -outform PEM bob_cert.pem

Bob receives the encrypted communication and starts decrypting it:

openssl smime -decrypt -in signed_message.asc -recip bob_cert.pem -inkey bob_private.key -out decrypted_signed_message.pem

openssl cms -decrypt -in signed_message.asc -recip bob_cert.pem -inkey bob_private.key -out decrypted_signed_message.pem

In general the digital signature validates the sender by showing that the message was signed by sender's private key that only they have access to.
The recipient can use the sender's public key to verify the signature ensuring sender authenticity and sees that the message has not been altered ensuring integrity.
